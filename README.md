Car Price Prediction using Linear Regression

This project develops a machine learning model to predict automobile prices using Linear Regression. The dataset was obtained from Kaggle and contains 205 car records with various technical and design specifications, including engine size, horsepower, fuel type, body style, curb weight, fuel system, city MPG, highway MPG, and other vehicle characteristics.

The project follows a structured data science workflow that includes data preprocessing, exploratory data analysis, feature selection, model development, and performance evaluation. Since the dataset contains no missing values, all observations are retained for analysis. The data is cleaned and prepared using R, after which a Linear Regression model is built to estimate car prices based on the selected features.

Objectives
Clean and preprocess the dataset.
Explore relationships between vehicle features and price.
Build a Linear Regression model for price prediction.
Evaluate model performance using statistical metrics.
Identify the most influential factors affecting car prices.

Target Variable: Price
